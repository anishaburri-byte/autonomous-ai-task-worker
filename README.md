# TaskPilot — Autonomous AI Task Worker

TaskPilot is an autonomous AI task worker designed to interpret natural-language instructions and execute tasks using tools, structured workflows, and verification.

## Features

- Natural-language task interpretation
- Invoice processing workflows
- Backend and frontend architecture
- Task execution and result verification
- Error handling and recovery

## Tech Stack

- Python
- Streamlit (if used by the current interface)
- SQLite (if used by the current backend)
- HTML, CSS, and JavaScript (if used by the frontend)

## Project Structure

- `backend/` — Backend application and task-processing logic
- `frontend/` — Frontend interface
- `.env.example` — Example environment configuration
- `AUDIT_REPORT.md` — Project audit report
- `ISSUES_FOUND.md` — Documented issues

## Setup

1. Clone the repository.
2. Install the dependencies required by the backend and frontend.
3. Configure environment variables using `.env.example`.
4. Start the backend and frontend using the project's setup instructions.

Refer to the source files and dependency manifests for the exact installation and run commands.

## Security

Never commit API keys, passwords, access tokens, or private invoice data.
